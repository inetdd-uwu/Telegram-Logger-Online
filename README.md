#tg-online-logger

Написал скрипт, который чекает онлайн в Telegram. Сделано на Playwright, работает через веб версию. Смысл такой, чтобы не сидеть и не обновлять профиль руками. Скрипт сам заходит в чат, раз в 50 секунд проверяет статус, и если человек в сети пишет время в текстовый файл. Удобно собирать стату заходов если надо. Для работы нужен Python, сам Playwright и Firefox для него. Еще по дефолту в коде прописан прокси, так что либо запусти свой либо просто удали эту строчку если прокси не юзаешь. Если сидишь на NixOS как я, запуск выглядит вот так: nix-shell -p python312Packages.playwright playwright-driver.browsers --run "python master.py". При запуске скрипт спросит имя файла для логов, ник человека без собачки и имя сессии. Если сессии с таким именем нет он создаст новую папку и откроет браузер чтобы ты залогинился. Дальше сам перейдет в чат и начнет мониторить. Логи падают в log/user а куки и профили аккаунтов лежат в папке session.Я в Python новичок так что код написан как получилось. Если увидишь косяки или знаешь как сделать нормально пиши буду рад фидбеку.

#tg-online-logger

Wrote a script that checks Telegram online status. Made with Playwright, works through the web version. The idea is to not sit there and refresh the profile manually. The script opens the chat, checks the status every 50 seconds, and if the person is online it writes the time to a text file. Useful for tracking login times if you need that. To run it you need Python, Playwright itself, and Firefox for it. Also there is a proxy hardcoded by default, so either start your own or just remove that line if you don't use a proxy. If you are on NixOS like me the launch command looks like this: nix-shell -p python312Packages.playwright playwright-driver.browsers --run "python master.py". When you start it the script asks for the log file name, the username without the @ symbol, and the session name. If there is no session with that name it will create a new folder and open the browser so you can log in. After that it goes to the chat and starts monitoring. Logs go to log/user and cookies plus account profiles are stored in the session folder. I am a beginner in Python so the code is written as best I could. If you see any issues or know how to do it better write to me, I would appreciate the feedback.
